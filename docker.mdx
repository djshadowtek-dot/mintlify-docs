Use the following Dockerfile snippet to build The Awesome on a pinned Ubuntu 26.04 base image. Pinning by digest ensures reproducible builds across environments.

```dockerfile Dockerfile
# Digest from https://hub.docker.com/_/ubuntu/tags?name=26.04
FROM ubuntu:26.04@sha256:513c074113a871b51a8d16ab445c88779d6452d937a164fb5cc479f32668a41d
FROM ubuntu:26.04@sha256:cd21a4f68a617580279d4b091cb18e3af9fa8a87500665f0ae5f7f757d17d367

ARG DEBIAN_FRONTEND=noninteractive
```
