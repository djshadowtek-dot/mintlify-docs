The Awesome uses API keys to authenticate requests. Every API call must include your key in the `Authorization: Bearer` header. API keys are tied to your account and carry your permissions — treat them like passwords.

## Generating an API Key

<Steps>
  <Step title="Open API Keys settings">
    Go to **Settings → API Keys** in your dashboard.
  </Step>
  <Step title="Create a new key">
    Click **Generate New Key** and enter a descriptive label that identifies where the key will be used — for example, `my-app-production`.
  </Step>
  <Step title="Copy the key immediately">
    Copy the key as soon as it appears. It is displayed **only once** and cannot be retrieved afterward.
  </Step>
  <Step title="Store the key securely">
    Save the key in an environment variable or a secrets manager (such as AWS Secrets Manager, HashiCorp Vault, or your CI/CD platform's secret store). Never hard-code it in source files.
  </Step>
</Steps>

<Warning>
  API keys are shown only once at creation. If you lose a key, revoke it immediately and generate a new one to maintain uninterrupted access.
</Warning>

## Using Your API Key

Pass your API key in the `Authorization` header on every request:

```bash
Authorization: Bearer YOUR_API_KEY
```

Here is a complete example using curl to list your data sources:

```bash
curl https://api.the-awesome.ai/v1/data-sources \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Use the tabs below to see how to authenticate with your preferred language or runtime.

<Tabs>
  <Tab title="Python">
    ```python
    import os
    import requests

    api_key = os.environ["AWESOME_API_KEY"]
    headers = {"Authorization": f"Bearer {api_key}"}

    response = requests.get(
        "https://api.the-awesome.ai/v1/data-sources",
        headers=headers
    )
    print(response.json())
    ```
  </Tab>
  <Tab title="Node.js">
    ```javascript
    const apiKey = process.env.AWESOME_API_KEY;

    const response = await fetch('https://api.the-awesome.ai/v1/data-sources', {
      headers: { 'Authorization': `Bearer ${apiKey}` }
    });
    const data = await response.json();
    console.log(data);
    ```
  </Tab>
</Tabs>

## Authentication Errors

| Status | Meaning | What to do |
|--------|---------|------------|
| `401 Unauthorized` | The key is missing or invalid. | Double-check that you are passing the correct value and that the key has not been revoked or expired. |
| `403 Forbidden` | The key is valid but lacks permission for this action. | For example, a read-only key cannot create or delete resources. Generate a key with the appropriate permissions, or upgrade your plan. |

## Revoking an API Key

To revoke a key, go to **Settings → API Keys** in your dashboard and click **Revoke** next to the key you want to invalidate. Revoked keys stop working immediately — any subsequent request using that key will receive a `401 Unauthorized` response.

<Tip>
  Rotate API keys regularly and use separate keys per application or environment (development, staging, production). This limits your blast radius if a key is ever compromised — you can revoke one key without disrupting all your other integrations.
</Tip>
