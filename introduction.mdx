## Four building blocks

Everything on the platform runs on the same four primitives:

- **Data Sources** — connections to your files, databases, and external APIs. Every analysis starts here.
- **Analysis Jobs** — AI-powered tasks that process a Data Source and produce Results.
- **Results** — structured insights, charts, and downloadable reports produced by a completed job.
- **Workflows** — automated sequences that run on a schedule or a trigger (new file, API event, webhook).
