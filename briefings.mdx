## The telemetry pipeline

**Wire it today. Ship it tonight.** The same real-time framework that fires briefings runs your live operational phase. Frames scream in over WebSocket, land out of order, dispatch to the renderer in strict sequence, and yank the system on catastrophic tail-risk before a human can flinch. No polling. No batch windows. No mercy for stale frames.

### Payload shape

```ts types/telemetry.ts icon=code lines
export interface AIPredictionOutcome {
  id: string;
  scenario: string;
  probability: number; // 0.0 to 1.0
  severity_if_failed: 'Low' | 'Medium' | 'High' | 'Catastrophic';
  action_required: 'Proceed_Autonomous' | 'Gated_Draft_Created' | 'Automated_Rollback_Triggered';
  visual_vector: [number, number, number];
}

export interface TelemetryPayload {
  timestamp: string;
  sequence_id: number;
  prediction_engine: string;
  target_system: string;
  outcomes: AIPredictionOutcome[];
}
```

### Consumer — drop it in, go live

Reconnect logic, sliding-window cache for out-of-order frames, strict sequential dispatch to your PixiJS/Canvas renderer, and a hard-wired catastrophic rollback hook. Copy it, wire the two callbacks, connect. That's the ship path.

```ts telemetryConsumer.ts expandable icon=code lines
export class TelemetryConsumer {
  private ws: WebSocket | null = null;
  private reconnectAttempts = 0;
  private maxReconnectAttempts = 5;
  private reconnectInterval = 2000; // 2 seconds

  // State management
  private lastProcessedSequenceId = -1;
  private frameCache: Map<number, TelemetryPayload> = new Map();
  private maxCacheSize = 50; // Sliding window for out-of-order frames

  // Configuration thresholds
  private readonly ROLLBACK_PROBABILITY_THRESHOLD = 0.005;

  constructor(
    private url: string,
    private onRenderUpdate: (payload: TelemetryPayload) => void,
    private onRollbackTriggered: (systemId: string, outcome: AIPredictionOutcome) => void
  ) {}

  public connect(): void {
    try {
      this.ws = new WebSocket(this.url);
      this.ws.binaryType = 'blob'; // Opt for arraybuffer if parsing Protocol Buffers
      this.initializeListeners();
    } catch (error) {
      this.handleReconnect();
    }
  }

  private initializeListeners(): void {
    if (!this.ws) return;

    this.ws.onopen = () => {
      console.log(`[Telemetry Connected] Established link to: ${this.url}`);
      this.reconnectAttempts = 0;
    };

    this.ws.onmessage = async (event: MessageEvent) => {
      try {
        let rawData: string;
        if (event.data instanceof Blob) {
          rawData = await event.data.text();
        } else {
          rawData = event.data;
        }
        const payload: TelemetryPayload = JSON.parse(rawData);
        this.processTelemetryFrame(payload);
      } catch (parseError) {
        // Drop malformed JSON silently to protect operational runtime loop
        console.error('[Telemetry Parse Error]', parseError);
      }
    };

    this.ws.onerror = (error) => {
      console.error('[Telemetry Socket Error]', error);
    };

    this.ws.onclose = (event) => {
      console.warn(`[Telemetry Closed] Code: ${event.code}. Attempting recovery...`);
      this.handleReconnect();
    };
  }

  private processTelemetryFrame(payload: TelemetryPayload): void {
    const seqId = payload.sequence_id;

    // 1. Drop late/duplicate frames arriving behind the pipeline cursor
    if (seqId <= this.lastProcessedSequenceId) return;

    // 2. Queue frame in sliding window
    this.frameCache.set(seqId, payload);
    if (this.frameCache.size > this.maxCacheSize) {
      const oldestKey = Math.min(...this.frameCache.keys());
      this.frameCache.delete(oldestKey);
    }

    // 3. Process sequential continuous frames
    let nextExpectedSeq = this.lastProcessedSequenceId + 1;
    while (this.frameCache.has(nextExpectedSeq)) {
      const currentFrame = this.frameCache.get(nextExpectedSeq)!;

      this.evaluateSafetyTriggers(currentFrame);
      this.onRenderUpdate(currentFrame); // Dispatch to PixiJS/Canvas renderer
      this.lastProcessedSequenceId = nextExpectedSeq;
      this.frameCache.delete(nextExpectedSeq);
      nextExpectedSeq++;
    }
  }

  private evaluateSafetyTriggers(frame: TelemetryPayload): void {
    for (const outcome of frame.outcomes) {
      if (
        outcome.severity_if_failed === 'Catastrophic' &&
        outcome.probability >= this.ROLLBACK_PROBABILITY_THRESHOLD &&
        outcome.action_required === 'Automated_Rollback_Triggered'
      ) {
        // Immediate human-bypass rollback hook execution
        this.onRollbackTriggered(frame.target_system, outcome);
        break; // Maximize efficiency; one catastrophic event stops evaluation
      }
    }
  }

  private handleReconnect(): void {
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      console.error('[Fatal] Telemetry reconnect limit reached. Gating system.');
      return;
    }
    this.reconnectAttempts++;
    setTimeout(() => {
      console.log(`[Reconnect] Attempt ${this.reconnectAttempts}/${this.maxReconnectAttempts}`);
      this.connect();
    }, this.reconnectInterval);
  }

  public disconnect(): void {
    if (this.ws) {
      this.ws.close(1000, 'Normal Closure');
      this.ws = null;
    }
  }
}
```

<Warning>
  `ROLLBACK_PROBABILITY_THRESHOLD = 0.005` is intentionally paranoid. Half a percent of catastrophic tail-risk is enough to yank the system. Tune with intent, not vibes.
</Warning>

<Tip>
  Two callbacks. `onRenderUpdate` feeds the canvas. `onRollbackTriggered` cuts the arm. Wire them both before you point this at production, then move.
</Tip>
